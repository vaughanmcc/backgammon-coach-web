# Backgammon Coach (web)

Play: https://vaughanmcc.github.io/backgammon-coach-web/

Backgammon against an Easy / Intermediate / Strong opponent, with a coach that plans
each roll and explains why. On a phone, hold it sideways; use Chrome's menu
"Add to Home screen" for an app icon.

This repository only holds the published web build (made with pygbag).
